# KaijuConverter Agent Skill (`kaijuconverter-mcp`)

Use this skill when an AI agent needs to inspect, validate, or convert documents, spreadsheets, vector graphics, e-books, scientific citations, or media files across **201+ formats**.

## Endpoints & Resources
- **Web Workbench & Format Encyclopedia:** [https://kaijuconverter.com](https://kaijuconverter.com)
- **MCP Discovery Manifest:** [https://kaijuconverter.com/api/mcp](https://kaijuconverter.com/api/mcp)
- **OpenAPI 3.1 Specification:** [https://kaijuconverter.com/api/openapi.json](https://kaijuconverter.com/api/openapi.json)
- **LLM Documentation Corpus:** [https://kaijuconverter.com/llms.txt](https://kaijuconverter.com/llms.txt)

## Capabilities
1. **Document & Archival Compliance:** Convert `PDF` to `PDF/A-1b` / `PDF/A-2b` (`ISO 19005`), merge/split/compress PDFs, and run OCR (`PDF -> TXT/DOCX`).
2. **Data Engineering & Analytics:** Transform `CSV`, `TSV`, `JSON`, `NDJSON`, `XLSX`, `ODS`, `SQLite`, and `Parquet`.
3. **Academic & Technical Publishing:** Convert `LaTeX (.tex)`, `BibTeX (.bib)`, `RIS (.ris)`, `Markdown (.md)`, `Typst`, `EPUB`, and `DOCX`.
