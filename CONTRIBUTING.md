## How Can You Contribute?

1. **Reporting Bugs**:
   - Verify the bug occurs on the latest commit of the `main` branch.
   - For security vulnerabilities, follow the guidelines in [SECURITY.md](SECURITY.md) and report via [https://kaijuconverter.com/security](https://kaijuconverter.com/security).
   - Provide minimal reproduction samples and CLI / API logs.

2. **Proposing Enhancements**:
   - Open a GitHub Discussion or Issue describing the feature, supported formats, and anticipated use case.
   - Reference the matching format specification in [Formats Directory](https://kaijuconverter.com/formats).

3. **Submitting Pull Requests**:
   - Fork the repository and create a descriptive feature branch (`git checkout -b feature/awesome-addition`).
   - Write unit tests covering new format handlers, transformations, or CLI flags.
   - Ensure clean code formatting adhering to project linters and style guides.
   - Commit with clear semantic commit messages (`feat:`, `fix:`, `docs:`, `test:`).
   - Push your branch and open a Pull Request targeting `main`.
